# AI Chatbot

A responsive web-based chatbot powered by Mistral AI 7B model, featuring dark/light mode toggle and streaming responses.

## Features
- Real-time chat with Mistral AI 7B
- Dark/Light mode toggle
- Smooth streaming responses
- Mobile-friendly design

## Setup
1. Clone this repository
2. Add your Mistral API key in Netlify environment variables as `VITE_API_KEY`
3. Deploy to Netlify (drag-and-drop or via Git)

## Technologies Used
- HTML5, CSS3, JavaScript
- Mistral AI API
- Netlify for deployment

## How to Use
1. Type your message in the input box
2. Press Enter or click the send button
3. View the AI's streaming response
